# Emran Azizi — Portfolio

A personal portfolio website showcasing my background, education, certificates, skills, experience, and projects as a Software Engineering student. Available in both English and German.

**Live site:** https://emranaziziwebsite.github.io/Portfolio/
**Repository:** https://github.com/emranaziziwebsite/Portfolio

## Features

- Bilingual — full English (`index.html`) and German (`de.html`) versions with a language switcher
- Responsive design for desktop, tablet, and mobile
- Animated background rendered with HTML5 Canvas
- Interactive, scroll-triggered project dashboard covering coding, university, and personal projects
- Contact form powered by EmailJS — sends messages without a backend
- Sections: About, Certificates & Education, Academic Modules, Languages, Skills, Experience, Projects, Contact

## Built With

- HTML5 & CSS3 (CSS custom properties for theming)
- Vanilla JavaScript — no frameworks or build tools
- [Font Awesome](https://fontawesome.com/) for icons
- [Google Fonts — Inter](https://fonts.google.com/specimen/Inter)
- [EmailJS](https://www.emailjs.com/) for the contact form

## Running Locally

This is a static site — no build step or dependencies required.

```bash
git clone https://github.com/emranaziziwebsite/Portfolio.git
cd Portfolio
```

Then either open `index.html` directly in your browser, or serve it locally:

```bash
python -m http.server 4173
```

and visit `http://localhost:4173`.
